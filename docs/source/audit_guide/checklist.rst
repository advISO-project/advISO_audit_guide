===============================
Bioinformatics Audit Checklist
===============================

An audit checklist is a structured list of items used to guide the audit process and ensure that all relevant areas of a process are covered. You may wish to structure these items into themes

Wet lab checklist
------------------
- Pre examination
- Kits and reagents
- Equipment
- Examination procedures
- Personnel
- Report
- Quality Assurance


Often following a single SOP or procedure

Bioinformatics checklist
--------------------------

Map this from the risks identified in the sample journey, and the processes that are used to mitigate those risks. The checklist items below are suggestions, and you may wish to add or remove items based on your own risk assessment.

- Pre examination
- Kits and reagents would not apply in this context
- Equipment - think about this differently, as it may be a server or cloud instance, or a Galaxy instance, or a cluster, or a workstation, or laptops
- Examination procedures - think about this differently, as it may be a Galaxy workflow, or a script, or a pipeline, or a set of scripts and pipelines
- Databases - think about this differently, as it may be a reference genome, or a set of reference genomes, or a reference database, or a set of reference databases
- Software - version control and documentation of software used in the bioinformatics process
- Personnel - think about this differently, as it may be a bioinformatician, a data scientist, or a computational biologist
- Report - think about this differently, as it may be a Galaxy history, or a set of output files, or a report generated by a script or pipeline
- Quality Assurance - think about this differently, as it may be a set of QC metrics, or a set of QC scripts
