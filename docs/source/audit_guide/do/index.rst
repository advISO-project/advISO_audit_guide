======================
Do: audit modules
======================

Each section of the audit process is treated as its own module. Work through each module to identify where your laboratory is compliant with ISO standards and where improvements can be made. Each module contains a series of questions and prompts to guide you through the audit process, along with examples and best practices to help you implement effective audits.

You do not need to read modules in order
